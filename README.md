# Hilda Natividad — «La mujer que siempre florece» 🌻
### 43 años floreciendo

Experiencia digital interactiva, botánica y editorial creada como regalo de cumpleaños para **Hilda Natividad Morales Luna** en sus **43 años**.

---

## Las 8 escenas narrativas

1. **Escena 1 — Bienvenida («Un jardín preparado para ti»)**: Girasol central que florece desde el capullo, partículas doradas y activación segura del audio ambiental local.
2. **Escena 2 — Celebración («43 años floreciendo»)**: Homenaje principal con retrato editorial enmarcado e iluminación cálida.
3. **Escena 3 — Su esencia («La luz que hace especial a Hilda»)**: Constelación botánica con sus valores fundamentales, tributo a su papel como madre y rincón emotivo para su enseñanza *«En el afán de ser hombre no olvides la magia de ser niño»*.
4. **Escena 4 — Recuerdos («Pequeños momentos, grandes historias»)**: Álbum fotográfico interactivo con filtros por categoría (*Hilda sola*, *Hilda conmigo*, *Momentos familiares*, *Viajes y aventuras*, *Celebraciones*, *Momentos cotidianos*) y visor *Lightbox*.
5. **Escena 5 — Una mujer que nunca deja de florecer**: Homenaje a su vocación como docente de Lengua Castellana, su Especialización en Docencia y TIC y su presente cursando su Maestría.
6. **Escena 6 — El jardín de sus recuerdos**: Gran girasol SVG interactivo con 8 pétalos seleccionables, contador de recuerdos descubiertos y adaptación ergonómica para celular y escritorio.
7. **Escena 7 — Un acróstico para ti**: Poema original de 25 versos con las iniciales exactas de **HILDA NATIVIDAD MORALES LUNA** y revelación progresiva.
8. **Escena 8 — Carta de su hijo y despedida**: Sobre artesanal con sello de lacre que despliega la carta personal de su hijo, seguido de la dedicatoria musical mediante **Spotify Embed** oficial (con atenuación automática del audio ambiental) y el mensaje final de despedida.

---

## Ejecución local y personalización

```powershell
# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

# Compilar para producción (GitHub Pages)
npm run build

# Previsualizar versión compilada bajo la ruta base del repositorio
npm run preview
```

Consulta [**`COMO_PERSONALIZAR.md`**](./COMO_PERSONALIZAR.md) para instrucciones detalladas sobre cómo agregar tus fotografías reales, reemplazar el audio ambiental, configurar tu canción de Spotify y publicar gratis en **GitHub Pages**.
